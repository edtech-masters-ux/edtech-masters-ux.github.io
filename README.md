# تجربة المستخدم في البيئات التعليمية الرقمية

مسار تعلم رقمي من أربع وحدات، منشور موقعا ثابتا على GitHub Pages.

- `index.html` و`style.css` و`app.js`: مشغل المقرر (بلا أي مكتبات خارجية).
- `data.js`: محتوى الوحدات الأربع.
- `assets/`: الصور والفيديو والترجمة النصية.
- `fonts/`: خط Tajawal (رخصة SIL Open Font License).

يحفظ المتصفح تقدم المتعلمة محليا على جهازها.
